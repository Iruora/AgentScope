Every agent. Every action.
One view.

AgentScope shows every AI coding agent running on your machine, the subagents it started, what each one is doing right now, and which ones are waiting for your approval.

Download AgentScope View on GitHub

All downloads are on the latest release.

Stop checking terminals to see who is stuck

When an agent needs you, AgentScope tells you, and Go to agent takes you straight to its terminal or editor.

Approvals in one inbox

Every permission prompt across every harness, oldest first. Approve or deny Claude Code prompts right there, from the tray, or get a push on your phone.

Subagents, live

See the tree of subagents each session started and what each one is running, as it happens.

Jump anywhere

Press Ctrl or ⌘ K to find any session, or set a global shortcut that focuses the agent that has waited longest.

History and diagnostics

Ended sessions stay searchable for as long as you choose. Pin and tag the ones that matter, and export any of them as Markdown.

Stuck and loop alerts

Know when a tool has run for ten minutes, a command keeps failing, or two agents are editing the same file.

What it cost, what it changed

Estimated cost per day, repo and model, and the files each session wrote with their diffs.

Works with the agents you already use

One click connects each harness. AgentScope shows you the exact config change first and backs up the original.

Observe by default. Local only. Reversible.

Never changes what an agent does on its own

It answers a prompt only when you turn that on and click Approve or Deny. Its hooks fail open, so even a broken install cannot block an agent.

Nothing leaves your machine

Everything is read and stored locally. The only network calls are the update check, which you can turn off, and phone push if you turn it on. No telemetry.

Easy to undo

Disconnect removes exactly what was added. Updates are signed and checked before they install.

Install

Download the installer for your system from the latest release, or use a package manager:

brew install --cask iruora/agentscope/agentscope   # macOS
winget install Iruora.AgentScope                   # Windows
scoop bucket add agentscope https://github.com/Iruora/scoop-agentscope
scoop install agentscope                           # Windows
yay -S agentscope-bin                              # Arch Linux

The builds are not code signed yet, so macOS and Windows ask you to confirm once before the first launch. The README shows how.
